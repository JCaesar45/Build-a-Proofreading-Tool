# LEXARA — The Atelier of Perfect Words

A breathtaking, luxurious single-page proofreading laboratory demonstrating advanced palindrome detection and repeated phrase analysis.

## Vision
Created as a love letter to linguistic craftsmanship. Every pixel, transition, and interaction was obsessively refined to evoke the feeling of working inside a high-end 2026 literary atelier.

### Core Engine Features
- Pure vanilla JavaScript palindrome symmetry engine (case-insensitive)
- Sophisticated sliding-window repeated phrase detection (including first occurrence)
- Real-time visual analysis with elegant micro-interactions
- Zero external framework dependencies beyond Tailwind CDN

### Technical Excellence
- Advanced glassmorphism + gold accent system
- Custom particle field background
- Responsive cinematic layout
- Fully accessible semantic HTML5

**Live Demo**: Open `index.html` in any modern browser.

Built with passion in Wheaton, Illinois.
